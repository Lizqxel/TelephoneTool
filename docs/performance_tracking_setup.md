# 実績集計の導入手順

既存Googleフォーム、既存Apps Script、既存シートは変更しません。実績機能は独立したApps Scriptから、同じスプレッドシート内に `TT_` で始まる専用シートだけを追加します。

## 事前バックアップ

1. 対象スプレッドシートを開く。
2. `ファイル` → `コピーを作成` で全体コピーを保存する。
3. 既存Apps ScriptのデプロイURLとバージョンを控える。

## 新しいApps Scriptの作成

1. [Google Apps Script](https://script.google.com/) で新しい独立プロジェクトを作成する。
2. `apps_script/performance_tracking.gs` の内容を貼り付ける。
3. プロジェクト設定の「スクリプト プロパティ」に以下を追加する。
   - `SPREADSHEET_ID`: 対象スプレッドシートURLの `/d/` と `/edit` の間の文字列
   - `SHARED_TOKEN`: 十分に長いランダム文字列
4. エディタから `setupPerformanceTracking` を1回実行し、権限を許可する。
5. `TT_実績受信`、`TT_実績修正`、`TT_架電明細`、`TT_時間帯集計` が追加されたことを確認する。

## Webアプリとして公開

1. `デプロイ` → `新しいデプロイ` → `ウェブアプリ` を選択する。
2. 実行ユーザーは自分、アクセスできるユーザーは運用環境に合わせて設定する。
3. 発行された `/exec` URLを控える。
4. TelephoneToolの `設定` → `実績集計・同期` にURLと `SHARED_TOKEN` を入力する。
5. 同期間隔を30秒にして保存する。

## 管理者による修正

`TT_実績修正` へ次のように補正値を入力します。元データは変更しません。

- 1件増加: `1`
- 1件減少: `-1`
- 対話時間30秒増加: 対話秒数補正へ `30`
- 無効化: 有効列へ `FALSE`

## 復旧・停止

1. TelephoneToolの設定で「実績収集を有効にする」をオフにする。
2. Apps Scriptで `setPerformanceEnabled(false)` を実行する。
3. 必要なら `backupPerformanceSheets()` を実行して専用シートのコピーを作る。
4. `TT_` で始まる4シートだけを削除または非表示にする。

既存Googleフォームと既存転記機能には影響しません。
